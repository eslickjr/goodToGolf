# Good2Golf
  
  ## Description
  It allows you to check the weather in your area or other areas to determine if the weather will be good for golf.
  ## Table of Contents
  - [Installation](#installation)
  - [Usage](#usage)
  - [License](#license)

  ## Installation
  You will need to pull the repository and then run npm run install, followed by npm run start:dev. From there you will be able to visit the front end and access the weather application at http://localhost:3000/. Alternatively, you can visit the live deployed website at https://goodtogolf.onrender.com/.
  ## Usage
  You simply go to the site and insert a city name of your choice and press search and it will present you with a five day forecast. You can also click on previously searched cities and delete previous searches.
